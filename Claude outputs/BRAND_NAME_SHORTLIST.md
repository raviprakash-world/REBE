# BRAND NAME SHORTLIST — 2026-09-21 (preliminary screen, NOT trademark clearance)

## Method (what was actually run)
- DNS lookup of .in / .com for ~50 short candidates (cloud shell). "no-dns" = no address record found. It does NOT prove the domain is unregistered (registered-but-unused domains also show no-dns). RDAP/WHOIS lookups were blocked by the network policy, so real availability is UNCHECKED.
- Web search per top candidate (titles only = leads, not facts).
- Not done: IP India trademark search, meaning check by native speakers, social handle check.

## FACT: findings
- Almost every short Hindi plant word already resolves on .com and .in (kopal, pallav, ropa, patta, beej, ankur, paudha, harit, hara... and most coined variants). Short dictionary words are effectively gone.
- Existing plant-seller names found in search results (leads): Gamla (gamla.shop), Gamala Planter (IKIRU), Hariyali / Haryali family (several nurseries, hariyali.biz, haryali.co.in), Paudha / Paudhewale / Paudhshala / Paudhe Se Yaari, Kyari (excluded by founder).
- Names with no DNS on both .in and .com: kopli, paudhu, chhatbagh, gamli, paudhi, ropee, gharkabagh, hariyala.

## Recommendation (mine, labelled)
1. Do NOT rename the codebase yet. The evidence does not support a "no trademark issue" guarantee for any name here.
2. If you want a swap, start with Kopli as the leading candidate, but only after: (a) ask 5 Delhi people what it sounds like/means, (b) register-check at a domain registrar (real WHOIS), (c) IP India public search, classes 31 (live plants), 35 (online retail), 21 (planters), (d) a trademark attorney's opinion before spending on branding.
3. Cheaper alternative: keep "Folia" (already built, easy to say) and run the same three checks on it. A name search costs less than a rebrand.
